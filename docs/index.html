Why it exists

Local evidence before heavy profiling stacks.

01

Run locally

The website is a showcase; CLI and Web UI benchmarks execute on the user's own machine.

02

Compare precision modes

Benchmark FP32 baselines against simulated INT8 and shift-only approximations.

Export artifacts

Generate summary CSV, Markdown reports, latency plots, and numerical error plots.

04

Compare real backends

Optionally measure PyTorch and ONNX Runtime CPU/CUDA kernels against the NumPy baseline.

Install

Clone it. Run it. Keep the artifact trail.

TinyEdgeBench is packaged as a Python project with a Streamlit Web UI and pytest coverage for the benchmark core. 

git clone https://github.com/keys2023190905023/TinyEdgeBench.git
cd TinyEdgeBench
python -m pip install -e ".[dev]"
python -m pip install -e ".[real-backends]"
python -m pip install -e ".[real-backends-gpu]"
python -m pytest
tinyedgebench web
